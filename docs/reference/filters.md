# Filter hooks

Generated by `mahout-devtools`. Do not edit by hand; run `composer hooks:generate`.

Every hook name is a `public const` on a `Hooks` class; its `@action` or `@filter` docblock tag decides which of the two documents the entry lands in.
The other kind lives in `actions.md`.

| Constant | Hook | Arguments | Since | Description |
|---|---|---|---|---|
| `WP_HEADERS` | `wp_headers` | `\WP $wp` | 1.0 | Core's response-header filter, inside WP::send_headers() and before any header is sent. RenderProvider resolves the request's SurfacePlan here, once, and merges the HeaderPolicy's headers into core's. |
| `SURFACE_CONTEXT` | `howdah/surface/context` | `\Iniznet\Mahout\Render\QueryContext $ctx` | 1.0 | Runs before the dispatch table matches. Subscribers receive the QueryContext and return one; a subscriber that returns anything else is refused, never coerced. |
| `SURFACE_RESOLVE` | `howdah/surface/resolve` | `\Iniznet\Mahout\Render\SurfacePlan $plan`, `\Iniznet\Mahout\Render\QueryContext $ctx` | 1.0 | Runs after the dispatch table matched. Subscribers receive the SurfacePlan and return one; a Surface is replaced through this filter, typed and greppable, never through filename shadowing. A plan's cacheability declaration survives the filter because the value object is readonly. |
| `SURFACE_RENDERED` | `howdah/surface/rendered` | `string $html`, `\Iniznet\Mahout\Render\Component $surface`, `\Iniznet\Mahout\Render\QueryContext $ctx` | 1.0 | Runs after the page's bytes exist. Subscribers receive the HTML, the Surface that produced it and the request facts. |
| `THE_CONTENT` | `the_content` | `string $content` | 1.0 | Core's content filter. PostMapper runs raw post content through it — kses, blocks and shortcodes — in the one boundary where content leaves the request's hands; the mapper is the taint escape's owner. |
| `MIGRATIONS` | `mahout/db/migrations` | `list<\Iniznet\Mahout\Db\Contracts\Migration> $migrations` | 1.0 | The migration filter mahout-db reads the site's declared migrations from. ContentProvider registers the search index's migration here, in register() — the ledger is built when the db provider boots, which is before this provider's boot. |
