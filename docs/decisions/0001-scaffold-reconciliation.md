# ADR 0001 — Scaffold reconciliation

Date: 2026-09-22 · Status: accepted

## Context

The theme was assembled from the mahout-scaffold generator, whose standalone
self-documentation differs from this repository's working contract. The
scaffold's README describes a generic starter; this repository's `AGENTS.md`
and its planning documents are the authority for what the theme is.

## Decision

The scaffold's framework-neutral files stay byte-identical to the scaffold's
stubs (verified by the scaffold's drift check). Everything the theme must
change is changed here, in this repository, and recorded in this directory.

Three deltas are deliberate and permanent:

1. **The working contract is repository-local.** `AGENTS.md` here is the
   canonical discipline contract; the scaffold's standalone copy is not
   consulted. The scaffold ships its own copy so an empty generated theme
   reads coherently before it is extended; this repository replaced it at
   birth.
2. **The scaffold's block-mode template stub is not adopted.** The scaffold's
   `stubs/modes/block/templates/index.html` ships `templates/index.html` — a
   slug this theme refuses: `index` is the Surfaces entry point, and shipping
   it would replace the dispatch table with a fixed template. The theme's
   slug gate (tests/Support/BlockSlugPolicy.php) refuses the stub as shipped
   (1 offence) and accepts a corrected tree that declares an editorial slug
   with its reason. A block-mode theme composes from an editorial declaration,
   never from the stub.
3. **The composition root renders through the dispatch table.** The scaffold's
   `Bootstrap` stops at booting providers; this repository's `Bootstrap::render()`
   resolves the request through `Surfaces` and returns the page, and
   `index.php` echoes it.

## Consequences

- `AGENTS.md` drifts from the scaffold's copy — reported by the scaffold's
  drift check and accepted here.
- The generated documents (`docs/reference/*.md`, `languages/howdah.pot`)
  are regenerated by their gates, never hand-edited.
- The drift check's remaining drifted files (`app/Bootstrap.php`,
  `app/Exception/NotBooted.php`, `app/Providers/AssetsProvider.php`,
  `index.php`, `tests/bootstrap.php`) are exactly the files the structural
  core must own.
